# Khalid El Kadi Assim — Portafolio profesional

Sitio estático preparado para GitHub Pages. Abre `index.html` para revisar la web.

## Publicar

En Settings → Pages: Source «Deploy from a branch», rama `main`, carpeta `/(root)`.

## Contenido

Trayectoria, formación y proyectos con interfaces navegables de GG Radar, CIE y Brasa & Oliva. Las aplicaciones incluidas son copias para demostración: GG Radar usa datos del proyecto de septiembre de 2026 y no llama a la API; CIE contiene muestras limitadas y no es una herramienta clínica validada; Brasa & Oliva es un negocio ficticio y no envía pedidos. Las ideas conceptuales se identifican como tales.

El CV descargable es el original aportado por el titular.

No requiere instalación, compilación, claves ni servicios externos. Los visores aíslan las aplicaciones y bloquean sus conexiones de red.

## Mantenimiento

La portada es `index.html`; el acabado visual está en `styles.css` y las interacciones en `script.js` y `logic.js`. Las fichas se encuentran en `proyectos/`, las aplicaciones en `apps/` y las imágenes en `assets/`.
